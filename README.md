# Semon Benyamin Portfolio

موقع HTML وCSS وJavaScript جاهز للنشر على GitHub Pages.

1. فك ضغط الملف. هتلاقي `index.html` في أول مستوى، ومعاه مجلدات `assets` و`work`.
2. اعمل Repository جديد باسم `semon-portfolio` واختار **Public** لو حسابك على GitHub Free.
3. من **Add file → Upload files** اسحب محتويات الملف بعد فك الضغط، بما فيها المجلدات. اعمل **Commit changes** على فرع `main`.
4. من **Settings → Pages** اختار **Deploy from a branch**، وبعدها **main** و**/(root)**، واضغط **Save**.
5. بعد النشر، انسخ رابط الموقع من **Settings → Pages**. لو اسم الحساب `semonbenyamen` والريبو `semon-portfolio`، الرابط هيبقى `https://semonbenyamen.github.io/semon-portfolio/`.

الموقع فيه نسخة PDF من الـCV متاحة للتحميل. فتح `index.html` في المتصفح يتيح معاينة الموقع قبل رفعه.
